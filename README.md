# СтройМатериал+ — лендинг стройматериалов

Одностраничный сайт для продажи строительных материалов с предзаказом. Готов к публикации на **GitHub Pages** без серверной части.

## Структура проекта

```
├── index.html      — разметка страницы (русский язык)
├── css/styles.css  — стили
├── js/main.js      — меню, плавная прокрутка, формы
├── .nojekyll       — отключение Jekyll на GitHub Pages
└── README.md
```

## Локальный просмотр

Откройте `index.html` в браузере (двойной щелчок или «Открыть с помощью»). Все пути относительные — сайт работает и как `file://`, и с GitHub Pages.

## Публикация на GitHub Pages

1. Создайте репозиторий на [GitHub](https://github.com/new) (например, `stroymaterial-landing`).
2. В папке проекта выполните:

   ```bash
   git init
   git add .
   git commit -m "Добавлен лендинг стройматериалов"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/stroymaterial-landing.git
   git push -u origin main
   ```

3. На GitHub: **Settings → Pages**.
4. **Source**: Deploy from a branch.
5. **Branch**: `main`, папка **`/ (root)`**.
6. Сохраните. Через 1–3 минуты сайт будет доступен по адресу:

   `https://ВАШ_ЛОГИН.github.io/stroymaterial-landing/`

   (если репозиторий называется `username.github.io`, сайт откроется по корневому домену без имени репозитория в URL).

## Настройка под себя

| Что изменить | Где |
|--------------|-----|
| Телефон | `index.html` — поиск `+7 (900) 123-45-67` и `tel:+79001234567` |
| Email для заявок | `js/main.js` — константа `ORDER_EMAIL` |
| Название компании | `index.html` — логотип, заголовки, footer |
| Товары и цены | секция `#catalog` в `index.html` + опции в `<select id="product">` |
| Адрес и email в контактах | секция `#contact` в `index.html` |

После правок закоммитьте и запушьте — GitHub Pages обновится автоматически.

## Форма предзаказа

При отправке открывается почтовый клиент (`mailto:`) с заполненным письмом. На странице показывается сообщение об успешной отправке. Для автоматической обработки заявок без почты можно подключить [Formspree](https://formspree.io/) или аналог — замените обработчик в `js/main.js`.
